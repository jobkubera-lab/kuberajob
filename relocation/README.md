# Kubera Relocation MVP

Бесплатный статический клиентский инструмент внутри сайта Kubera Job.

## Возможности

- экспресс-анкета по переезду в Сербию или Черногорию;
- предварительная рекомендация страны;
- ориентировочная оценка финансового резерва;
- персональный стартовый чек-лист;
- генерация заявки для отправки консультанту;
- никаких платных API, серверов или баз данных.

## Публикация

Папка `relocation/` совместима с GitHub Pages и открывается как подраздел существующего сайта.

## Важно

Инструмент предоставляет информационную предварительную оценку. Он не является юридической консультацией, не гарантирует ВНЖ и не хранит паспортные данные. Миграционные требования должны проверяться по официальным источникам перед работой с клиентом.
