## What's in this repository

### `/relocation`

A **free, static client-side tool** for relocation/visa planning.

**Features:**
- Express questionnaire for Serbia or Montenegro relocation
- Country recommendation algorithm
- Financial reserve estimation
- Personalized startup checklist
- Request generation for consultant follow-up
- No backend, no paid APIs, no database

**Technology:** HTML5 + JavaScript (fully offline-capable)

**Published via:** GitHub Pages (subdirectory of original Kubera Job site)

**Language:** Russian (partially English-compatible)

### `/visa-playbooks`

Older visa and country-specific guidance (now superseded by [`kubera-visa-playbooks`](https://github.com/jobkubera-lab/kubera-visa-playbooks) repository).
